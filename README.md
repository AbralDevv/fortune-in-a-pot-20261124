# Fortune in a Pot

One kind, funny fortune for a houseplant on the windowsill, in 120
characters or fewer. `main.ts` writes the single line to
`/output/entry.txt`, gated to 1–120 characters, one line, plain ASCII.

## Run

```sh
bun main.ts
```

## Entry

> This week a sunbeam will pick your favourite leaf, and you will grow a little taller just to say thank you.

107 characters.
